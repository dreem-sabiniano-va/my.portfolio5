# Dreem Sabiniano — Portfolio

A responsive portfolio built with HTML, CSS, and vanilla JavaScript. Open `index.html` in a browser to view it, or publish this folder as a static site.

## Included

- Six service cards and grouped tools, including Notion, Calendly, ClickUp, and Asana
- Interactive task hand-off quiz
- Clickable project collection with project details and live Notion links
- Responsive navigation, scroll reveal, and reduced-motion support
- Existing portrait, artwork, and downloadable project files

The Pool & Sauna Operations Hub and Brooks Creative Studio Calendar Hub are self-directed sample projects. Their Notion pages must be shared publicly for visitors to open them.
